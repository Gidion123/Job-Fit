It applies JD prompt v1.4, evidence prompt v1.1, quote validator v1.1, G1/G2 and local masking of synthetic CVs. The [frozen plan](../../../evals/results/cp23/end_to_end_dev/cp23_end_to_end_dev_20261004_v1/plan.json) records input hashes and the US$2 aggregate cap. No workbook, gold, source or split file is written.

No earlier stage file was rewritten.
