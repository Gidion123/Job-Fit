# CP2.3 Version Path Map

**4 October 2026. Status: compatibility plan; no historical input was moved.**

The provisional development freeze exists in [D-068](decisions.md). Several frozen experiment plans record both a file path and its SHA-256 hash. Moving a prompt, CV, guideline, model registry or result file now would make the recorded path unavailable even if its contents were copied without change. A mass path rewrite would also change the evidence being audited. The original paths therefore remain canonical through CP2.4. This is a deliberate compatibility decision, not a claim that a folder migration was completed.
