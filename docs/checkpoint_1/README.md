## How to use these reports

Read them in order to see the flow: problem, data, processing, EDA, then design decisions. Each report can be read on its own, but numbers that use different populations must not be combined without checking the denominator.

All reporting stages from CP1.1 to CP1.6 are complete, with explicit limitations: the source choice is provisional, dedup is still v0 (the 3 UNSURE pairs are flagged for re-check), the labels are rule-based v0 (their accuracy will be measured against the CP2 gold set), and gold-set and model metrics are not measured yet. The next stage, CP2, follows the System Design v1.2; it does not repeat the collection.

If the data or rules change, run the notebook, update the inventory and insights with `scripts/refresh_cp1_docs.py`, then review the six reports and their narrative manually. The script does not rewrite the six reports, and it does not automatically check that their interpretation is correct.
